# Morena Tropicana 👗

Sistema web de e-commerce desenvolvido para gestão e venda de roupas femininas, com foco em organização de produtos, clientes e pedidos, além de uma experiência personalizada de navegação.

---

## 📌 Sobre o projeto

O **Morena Tropicana** é um sistema web voltado para o gerenciamento de uma loja de roupas femininas. O projeto foi desenvolvido com base em requisitos funcionais que incluem controle de clientes, catálogo de produtos, gestão de pedidos e fluxo básico de vendas.

Além disso, o sistema conta com funcionalidades voltadas à personalização da experiência do usuário, permitindo maior interação com a plataforma.

---

## ⚙️ Funcionalidades

* Cadastro e gerenciamento de clientes
* Cadastro e gerenciamento de produtos
* Sistema de pedidos
* Controle básico de vendas
* Personalização de experiência do usuário (quiz de estilo)
* Organização de catálogo de produtos
* Interface web para interação com o sistema

---

## 🧠 Objetivo do sistema

O objetivo do Morena Tropicana é simular o funcionamento de uma loja virtual, permitindo o controle de operações básicas de um e-commerce, desde o cadastro de produtos até a finalização de pedidos, além de oferecer uma experiência mais personalizada ao usuário.

---

## 🛠️ Tecnologias utilizadas

* Desenvolvimento Web
* PHP
* HTML5
* CSS3
* JavaScript
* MySQL
* Git
